# EmailAgent

面向课程作业的 Electron 桌面邮件助手，支持 QQ 邮箱和 163 邮箱的收发、每日 AI 摘要及一句话写邮件。应用以中文显示，邮箱授权码只保存在本机；使用 AI 功能时，所选邮件片段会发送给用户自行配置的模型服务。

## 本地运行

需要 Node.js 22 或更新版本、npm 10 或更新版本，以及 macOS 桌面环境。

```bash
npm install
npm run dev
```

检查代码：

```bash
npm run typecheck
npm test
npm run build
npm run package:mac
```

## 添加邮箱

首次运行使用本地账号 `dmc`、密码 `123456` 登录；可在侧栏修改密码或添加其他本地用户。邮箱和 AI 配置按登录用户分别保存。

1. 在 QQ 邮箱或 163 邮箱网页设置中开启 IMAP/SMTP，并生成客户端授权码。
2. 在应用中点“添加邮箱”，选择服务商，输入完整邮箱地址和授权码。
3. 应用会分别测试 IMAP 和 SMTP；成功后才保存账户。

请使用客户端授权码，不要输入网页登录密码。授权码保存在由登录密码加密的本地用户数据中，不要把它写进源码、截图或提交记录。旧版 `safeStorage` 文件首次登录时会先备份再迁移；若无法解密，可在恢复界面重试或手动备份并重建。添加账户后可以查看收件箱、阅读邮件、撰写和回复。发信始终经过预览与确认。

## 配置 AI

打开“AI 设置”，输入兼容 Chat Completions 的 HTTPS 基础地址（通常以 `/v1` 结尾）和 API Key，点击“加载模型”后从下拉框选择模型，再保存配置。AI 配置与邮箱授权码一样只存于当前本地用户下。生成每日摘要会将当日邮件的发件人、主题、时间和部分正文发送给所选 AI 服务；不发送附件或邮箱授权码。自动摘要只在应用运行期间执行。

## 当前范围

- 邮件列表展示最近 50 封；每日摘要每个账户最多处理最近 30 封当日邮件。
- “与邮箱对话”可用一句话跨邮箱查找邮件、汇总待办、起草回复。默认查询全部邮箱近 90 天的收件箱和已发送，回答可点击来源邮件；候选过多时会提示缩小范围。
- 进入“与邮箱对话”会显示近 30 天的收发数量、常见往来人和内容星图；星图会把最多 20 封近期邮件的片段发送给已配置的 AI 服务。对话回答附应用内原邮件链接。
- 侧栏可选择亮色、暗色或跟随系统，偏好按当前本地用户保存。
- Agent 可提出标记已读、标记未读或归档；逐项确认后才写入邮箱。归档要求服务商已有归档文件夹。对话记录按当前本地用户加密保存 30 天，可在 Agent 页面清除。
- 邮件正文优先安全显示 HTML，缺失时显示纯文本；附件只显示名称。
- “已发送”读取服务商提供的 IMAP 文件夹。SMTP 发信后服务商是否自动保存副本，需要用真实邮箱验证。
- 真实 QQ/163 连接需要使用者在本机输入测试账号授权码；仓库不包含账号或密钥。
