# EmailAgent

面向课程作业的 Electron 桌面邮件助手，支持 QQ 邮箱和 163 邮箱的收发、每日 AI 摘要及一句话写邮件。应用以中文显示，邮件和授权码只保存在本机；AI 功能需要用户自行配置模型服务。

## 本地运行

需要 Node.js 22 或更新版本、npm 10 或更新版本，以及 macOS 桌面环境。

```bash
npm install
npm run dev
```

检查代码：

```bash
npm run typecheck
npm test
npm run build
npm run package:mac
```

## 添加邮箱

1. 在 QQ 邮箱或 163 邮箱网页设置中开启 IMAP/SMTP，并生成客户端授权码。
2. 在应用中点“添加邮箱”，选择服务商，输入完整邮箱地址和授权码。
3. 应用会分别测试 IMAP 和 SMTP；成功后才保存账户。

请使用客户端授权码，不要输入网页登录密码。授权码保存在 Electron `safeStorage` 加密的本地文件里，不要把它写进源码、截图或提交记录。添加账户后可以查看收件箱、阅读邮件、撰写和回复。发信始终经过预览与确认。

## 配置 AI

打开“AI 设置”，输入兼容 Chat Completions 的 HTTPS 基础地址（通常以 `/v1` 结尾）、模型名和 API Key。AI 配置与邮箱授权码一样只存于本机。生成每日摘要会将当日邮件的发件人、主题、时间和部分正文发送给所选 AI 服务；不发送附件或邮箱授权码。自动摘要只在应用运行期间执行。

## 当前范围

- 邮件列表展示最近 50 封；每日摘要每个账户最多处理最近 30 封当日邮件。
- 邮件正文以纯文本显示；附件只显示名称。
- “已发送”读取服务商提供的 IMAP 文件夹。SMTP 发信后服务商是否自动保存副本，需要用真实邮箱验证。
- 真实 QQ/163 连接需要使用者在本机输入测试账号授权码；仓库不包含账号或密钥。
